TOGETHER 5.0 — обновление существующего сайта
==========================================

Это обновление для GitHub footodor-dev/together-watch и Render.
Не удаляйте и не создавайте заново репозиторий и Render-сервис.

Замените на GitHub ровно четыре файла:
  server.js          → server.js (корень репозитория)
  public/index.html  → public/index.html
  public/app.js      → public/app.js
  public/styles.css  → public/styles.css

README-UPDATE.txt загружать необязательно. Не загружайте ZIP вместо файлов.
После Commit changes: Render → together-watch → Manual Deploy → Deploy latest commit.
Когда появится Deploy succeeded | Live, откройте сайт и нажмите Ctrl+Shift+R.

ЧТО ИЗМЕНИЛОСЬ
---------------
- Одна общая шкала перемотки для MP4/HLS. Встроенные controls у video отключены.
- YouTube: запрос режима controls=0 (но встроенные элементы/реклама иногда остаются по политике YouTube).
- Vimeo: запрос режима controls=false; доступность зависит от параметров видео и аккаунта владельца.
- Локальная кнопка включения/выключения звука фильма.
- Полноэкранный режим захватывает и общую полосу перемотки.
- «Тест без надписей» вставляет прямую ссылку на Big Buck Bunny.mp4.
- Кнопка микрофона теперь включает ГОЛОСОВОЙ ЧАТ (а не преобразование речи в текст).
- При первом включении микрофона браузер запрашивает разрешение; без клика доступ не запрашивается.
- При повторном нажатии микрофон выключается и перестаёт передаваться.
- Микрофон/голос только между членами одной комнаты; сервер пересылает WebRTC-сигналы, не аудиоданные.
- Для iPhone добавлена кнопка «🔊 Звук», если Safari не разрешил запуск голоса другого участника.
- Проверка тайминга фильма каждые 2 секунды.

КАК ПРОВЕРИТЬ ГОЛОС
-------------------
1. Ты создаёшь комнату на ноутбуке, отправляешь ссылку подруге.
2. На обоих устройствах нажмите кнопку микрофона и дайте браузеру разрешение.
3. Используйте наушники во избежание эха.
4. Если собеседника не слышно на iPhone, нажмите «🔊 Звук».
5. Чтобы выключить микрофон, нажмите его значок повторно.

ОГРАНИЧЕНИЯ
-----------
- Надписи «2200k avc1 ...» и логотип Unified Streaming из предыдущего HLS-источника
  являются частью самого демонстрационного видео: сайт не может убрать их из кадров.
  Кнопка «Тест без надписей» выбирает альтернативный MP4-источник.
- Чужую рекламу и DRM от сторонних сервисов сайт не устраняет.
- Аудиозвонки между разными странами могут не соединяться, если сети требуют TURN-реле.
  В Render можно задать переменную ICE_SERVERS_JSON с STUN+TURN-конфигурацией,
  если у вас есть собственный TURN-сервис. Не публикуйте учётные данные в GitHub.
- Звук вкладки при трансляции зависит от браузера: выбирайте «Поделиться аудио».
- Автоматическая пауза/перемотка работают только с поддерживаемыми видеоисточниками,
  не с произвольным плеером на чужом киносайте.
